1. Getting Started

DisasterBag is an emergency alert device that sends stress signals and status updates to your trusted contacts via Telegram and SMS. Before using the device, you must configure it with your contacts and communication preferences.

⚠️ Important: Ensure your ESP32 device is powered on and the SIM card is inserted before starting configuration.

2. Entering Config Mode

Config Mode allows you to set up Telegram Chat IDs, SMS phone numbers, and other device settings through a web interface.

How to Enter Config Mode

Step 1: Press and hold the Config Button (GPIO 32) for 2+ seconds until the display shows "CONFIG MODE ACTIVE"
Step 2: The device will create a WiFi hotspot named: DisasterBag-Setup
Step 3: On your phone/computer, connect to this WiFi hotspot (no password required)
Step 4: Open a web browser and go to: 192.168.4.1
Step 5: You should see the configuration page with all available options
✓ You are now in Config Mode and can update all settings

3. Telegram Setup

Telegram is the primary communication method for DisasterBag. It sends detailed alerts with location, time, and device status.

Step 1: Create a Telegram Bot

  1. Open Telegram app on your phone or go to web.telegram.org
  2. Search for @BotFather (official Telegram bot creator)
  3. Tap START to open BotFather
  4. Send the message: /newbot
  5. Follow the prompts:
    • Enter a name for your bot (e.g., "DisasterBag Alert Bot")
    • Enter a username (must end with "_bot", e.g., "DisasterBag_Alert_bot")
  6. BotFather will give you a token that looks like: 123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
  7. Copy this token - you'll need it in Config Mode

Step 2: Get Your Telegram Chat ID

  1. In Telegram, search for @userinfobot
  2. Tap START
  3. The bot will show your Chat ID (a long number)
  4. Copy this number - you'll need it for configuration
⚠️ Important: For EACH person who should receive alerts, they must:
  1. Search for your bot (e.g., @DisasterBag_Alert_bot)
  2. Tap START to activate the bot
  3. Get their own Chat ID from @userinfobot

Step 3: Configure in Device

Telegram Bot Token:
Paste your token from BotFather here. Example:
123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11
Telegram Chat IDs:
Enter each recipient's Chat ID, separated by commas (no spaces).
7176808640,1234567890,9876543210
✓ Save the configuration. Your device is now ready to send Telegram alerts!

4. SMS Configuration

SMS is a backup communication method that works with standard mobile phones. Messages are short but include location coordinates.

Adding SMS Recipients

Phone Numbers Format:
Enter phone numbers with country code, separated by commas:
+639351738229,+639967472407,+639123456789

For Philippines: +63 (remove leading 0 from local number)
Example: 09123456789 → +639123456789
⚠️ Note: SMS messages are limited to 160 characters and include location coordinates only. For full message details, use Telegram.

5. Button Controls

Button Action Result
Button 1 (GPIO 26) Single Tap Sends STRESS signal with location. Piezo beeps loudly. Alerts all contacts.
Button 1 (GPIO 26) Double Tap (within 800ms) Sends "I'm OK" / SAFE message. Device is functioning properly. Alerts all contacts.
Config Button (GPIO 32) Tap (<2 seconds) Device restarts. Used for quick reset.
Config Button (GPIO 32) Hold (2+ seconds) Enters CONFIG MODE. Creates WiFi hotspot for setup.

6. Device Settings

Available Configuration Options

Device Name:
Custom name that appears in alerts (e.g., "Mark's DisasterBag"). Max 30 characters.
Telegram Bot Token:
Your bot token from @BotFather (required for Telegram alerts).
Telegram Chat IDs:
Comma-separated list of recipient Chat IDs (required for Telegram alerts).
SMS Phone Numbers:
Comma-separated list of phone numbers with country codes (optional, for SMS alerts).

7. Troubleshooting

Device Won't Enter Config Mode

Problem: Config Button doesn't activate config mode

Solutions:
  • Make sure you hold the button for 2+ seconds (watch the display for confirmation)
  • Check that GPIO 32 is properly connected
  • Try a brief power cycle: remove USB power, wait 10 seconds, reconnect

WiFi Hotspot Not Appearing

Problem: Can't find DisasterBag-Setup WiFi after entering config mode

Solutions:
  • Check phone WiFi settings - enable WiFi if disabled
  • Look for networks starting with "Disaster" or check the device display for the actual SSID
  • Restart the device and try entering config mode again
  • Check device Serial Monitor to confirm config mode activation

Can't Access Configuration Page

Problem: Connected to WiFi but can't open 192.168.4.1

Solutions:
  • Make sure you're connected to DisasterBag-Setup WiFi (check WiFi settings)
  • Try different browsers or clear cache
  • Check device IP - look at Serial Monitor for actual IP address
  • Try connecting device directly with USB cable and open Serial Monitor to confirm WiFi is active

Telegram Alerts Not Received

Problem: Device sends alerts but Telegram doesn't receive them

Solutions:
  • Verify Telegram Chat IDs are correct (use @userinfobot to double-check)
  • Ensure each recipient has started the bot (press START in @YourBotName)
  • Check that Bot Token is correct (copy from @BotFather exactly)
  • Check Serial Monitor for "[TELEGRAM] Failed" messages indicating network issues
  • Test with 4G/mobile data instead of WiFi

SMS Not Sending

Problem: SMS alerts don't reach recipients

Solutions:
  • Verify phone numbers are formatted correctly with country code: +63XXXXXXXXXX
  • Remove any spaces or dashes from numbers
  • Check that SIM card has SMS plan enabled (contact your carrier)
  • Check Serial Monitor for "+CMS ERROR" messages - indicates SIM/carrier issue
  • Try sending to just one number first to test

Display Shows No Location

Problem: GPS not acquiring signal

Solutions:
  • Make sure device has clear view of sky (GPS needs satellite signal)
  • Wait at least 60 seconds for GPS first fix (longer in cities)
  • Try moving to an open area away from buildings
  • Device will use Last Known Location if GPS unavailable
