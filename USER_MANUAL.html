GPS Alert System - Complete User Manual

📖 Introduction

The DisasterBag GPS Alert System is a portable emergency notification device designed to help you stay safe during disasters and emergencies. It provides instant alerts to your trusted contacts via Telegram and SMS, includes GPS location tracking, and features easy-to-use buttons for quick emergency signaling.

This manual will guide you through setup, configuration, and daily usage of your DisasterBag device.

🚀 Quick Start Guide

What You Need Before Starting

  • A smartphone with Telegram app installed
  • At least one phone number for SMS alerts
  • The DisasterBag device charged and powered on
  • Good 4G LTE signal in your area

Initial Setup (First Time Only)

  1. Power on the device and wait for 30 seconds to boot
  2. Hold the CONFIG button (side of device) for 2+ seconds until display shows WiFi mode
  3. On your phone, look for WiFi network named "DisasterBag-Config"
  4. Connect to that WiFi network
  5. Open browser and go to 192.168.4.1
  6. Configure Telegram and SMS settings (see detailed instructions below)
  7. Click "Save" and device will restart
  8. You're ready to use!

🔘 Button Functions

Your DisasterBag has two main buttons for emergency alerts:

BUTTON 1 (Front)

Single Tap:
Sends "I'm OK" status message with your location to all configured recipients
Double Tap:
Same as single tap - confirms you're safe

CONFIG BUTTON (Side)

Hold 2+ Seconds:
Enters configuration mode - creates WiFi hotspot for settings
Single Tap:
Restarts the device
⚠️ Important: To send a STRESS/HELP alert, hold Button 1 for 2 seconds. The device will play a loud beep pattern and send alert messages to all recipients.

🆘 Emergency Usage (SOS Mode)

When You Need Help

  1. Hold the STRESS button (Button 1) for 2+ seconds
  2. You'll hear a loud beeping alarm sound
  3. Device will immediately send STRESS alerts to all configured contacts
  4. Message includes: Your name, current location (if available), and timestamp
  5. Telegram recipients get detailed information and map link
  6. SMS recipients get concise location information
✓ What Your Contacts Receive:
• Your device name and status
• GPS coordinates or last known location
• Clickable Google Maps link (Telegram only)
• Current date and time of alert

💬 Complete Telegram Setup

Step 1: Create a Telegram Bot

  1. Open Telegram app and search for @BotFather
  2. Tap on BotFather and select "START"
  3. Type /newbot and press enter
  4. Give your bot a name (e.g., "My DisasterBag")
  5. Give your bot a username (must end with "bot", e.g., "MyDisasterBag_bot")
  6. BotFather will give you a TOKEN - copy and save this token safely

Step 2: Get Your Telegram Chat ID

  1. Open Telegram and search for @userinfobot
  2. Start the bot and it will show your Telegram ID
  3. Copy the "Id" number (it looks like: 123456789)
  4. Do this for EACH person who should receive alerts
Example Chat IDs to add:
123456789 (Your ID)
987654321 (Family member)
555666777 (Emergency contact)
(Add one per line in the config)

Step 3: Activate Your Bot for Each User

  1. Have each recipient search for your bot username in Telegram (e.g., @MyDisasterBag_bot)
  2. Each person should tap START to activate the bot
  3. This is required - without it, the bot cannot send them messages

Step 4: Configure in DisasterBag

  1. Enter Config Mode: Hold CONFIG button for 2 seconds
  2. Open WiFi network "DisasterBag-Config" on your phone
  3. Go to 192.168.4.1 in your browser
  4. Under "Telegram Configuration":
  5. Paste your Bot Token in the "Bot Token" field
    Enter Chat IDs (one per line) in the "Chat IDs" field
    Example:
    123456789 987654321 555666777
  6. Click "Save Configuration"
  7. Device will restart and confirm setup on display
✓ Test Your Setup: Press Button 1 once. If all Telegram users receive a message, your setup is correct!

📱 SMS Setup

Adding Phone Numbers

  1. Enter Config Mode (hold CONFIG button 2+ seconds)
  2. Connect to WiFi network "DisasterBag-Config"
  3. Go to 192.168.4.1 in your browser
  4. Under "SMS Configuration":
  5. Enter phone numbers in international format:
    +[Country Code][Phone Number]
    Example: +639123456789 (Philippines)
    Example: +12025550123 (USA)

    One number per line
  6. Click "Save Configuration"

⚙️ Detailed Configuration Mode Instructions

Entering Configuration Mode

  1. Locate the CONFIG button: It's on the side of the device
  2. Hold it down: Press and hold for 2 seconds minimum
  3. Wait for confirmation: Display will show "CONFIG MODE" and create a WiFi hotspot
  4. Listen for buzzer: You'll hear a short beep confirming entry

Accessing the Configuration Portal

  1. On your smartphone, go to WiFi settings
  2. Look for network named "DisasterBag-Config"
  3. Connect to it (no password required)
  4. Open your browser and go to: 192.168.4.1
  5. You should see the configuration page with all settings

🔧 Troubleshooting

Problem: Can't find "DisasterBag-Config" WiFi network

Solution: Make sure CONFIG button is held for at least 2 seconds. You should hear a beep. Try again and wait 10 seconds. If still not visible, restart the device by holding CONFIG for 1 second (single tap).

Problem: Can't reach 192.168.4.1

Solution: Make sure you're connected to "DisasterBag-Config" WiFi. Check WiFi icon shows connected. Try typing the address in browser's address bar again with "http://" prefix: http://192.168.4.1

Problem: Telegram messages not sending

Solution: 1) Verify each recipient has started the bot (searched for bot username and tapped START in Telegram). 2) Check Chat IDs are correct (use @userinfobot to verify). 3) Verify Bot Token is correct (copy-paste from BotFather). 4) Check you have internet connection on device (signal bars visible).

Problem: SMS not sending

Solution: 1) Verify phone numbers have correct country code (e.g., +63 for Philippines). 2) Check device shows 4G signal. 3) Make sure numbers are in format: +[country][number]. 4) Test with a known working number first. 5) Check with phone provider if SMS receiving is blocked.

Problem: No GPS location showing

Solution: GPS takes 30 seconds to 2 minutes to lock. Make sure device is outdoors or near a window. Device will show "NO GPS" initially, which is normal. Once GPS locks, coordinates will appear on screen 2. Device uses cell tower location as backup if GPS unavailable.

Problem: Device not responding/frozen

Solution: Restart by holding CONFIG button for 1 second (single tap). If still frozen, wait 30 seconds for battery to drain, then recharge. As last resort, remove battery for 10 seconds and reinsert.

Problem: Weak or no 4G signal

Solution: Try moving to higher elevation or near a window. Check with your service provider if they have coverage in your area. Move away from tall buildings that may block signal. Consider relocating to an area with better coverage during emergencies.

❓ Frequently Asked Questions

Q: How often can I send alerts?

A: There's no limit. You can send as many alerts as needed. Each alert takes 5-10 seconds to send to all recipients.

Q: Can I change settings without entering config mode?

A: No. You must enter Config Mode to modify any settings. Settings are saved in device memory and only updated through the configuration portal.

Q: What happens if device loses internet?

A: Alerts will not send. Device will show signal bars at 0. Try moving to a location with better coverage or wait for connection to restore.

Q: Can I use the device for non-emergencies?

A: Yes! Press Button 1 for status updates anytime. It's useful for check-ins with family or confirming you're safe after earthquakes.

Q: How accurate is the GPS?

A: GPS accuracy is typically 5-10 meters in open areas. In cities with tall buildings (urban canyons), it may be 20-50 meters. Cell tower location is accurate to approximately 500 meters.

Q: What does the beep sound mean?

A: Different beep patterns indicate different functions. Three short beeps = alert sending. One beep = config mode entered. Device will beep to confirm button presses.

Q: Can multiple people access config mode?

A: Yes. Anyone with the device can hold the CONFIG button to modify settings. Consider this a security feature - only trusted people should have physical access to the device.
